Як користуватись

  1. Завантаж CSV або Excel файл із MGRS координатами та value.
  2. Натисни кнопку "Обробити".
  3. Якщо знайдено помилки — буде згенеровано Excel файл із підсвіченими рядками.
  4. Виправ помилки та завантаж файл повторно.
  5. При успішній обробці буде згенеровано CSV файл у форматі latitude,longitude,value.
  6. На мапі доступний preview у режимі точок або heatmap.
